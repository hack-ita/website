{{- /* payload — renders a template-injection / SSTI payload literally. Use this ONLY for payloads that contain the substrings "{{" + "<" or "{{" + "%", which Hugo would otherwise try to parse as a shortcode and fail to build. Ordinary payloads ({{7*7}}, {{config}}, ${7*7}, …) work fine in a normal fenced code block and don't need this. Pass the payload as a backtick-quoted argument so you don't have to escape quotes. The optional second argument is the language for a code block, or the keyword "inline" to render an inline element inside running text: {{< payload `${{<%[%'"}}%\` >}} → highlighted code block {{< payload `{{ ''.__class__ }}` "python" >}} → block, python highlight ...invia il polyglot {{< payload `${{<%...` "inline" >}} su ogni param */ -}} {{- $payload := .Get 0 -}} {{- $mode := .Get 1 | default "text" -}} {{- if eq $mode "inline" -}} {{ $payload }} {{- else -}} {{- transform.Highlight $payload $mode "" -}} {{- end -}}
